# DocQA – AI-based Document Question Answering (no NLP, no RAG)
Open `index.html` in any browser (no install/server, works offline).
- **Knowledge Base** tab: pick a sample, or paste/upload a structured .txt/.md/.csv (see `samples/`), press *Build*.
- **Ask** tab: answer + rule fired + confidence + source line + reasoning trace.
- **Evaluate** tab: edit `question => regex => type` tests and run.
- **Design** tab and `report.html` (IEEE-style report, Print → Save as PDF; tables computed live).
Files: index.html, style.css, app.js, report.html, samples/ (solar_system.md, ai_course.md, planets.csv).
