AI-Based Document Question Answering System Using Knowledge Representation and Rule-Based Reasoning

Abhishek P Shetty (Reg. No. 25ETAI410010)
Dept. of Computer Science and Engineering, Faculty of Engineering & Technology
Ramaiah University of Applied Sciences · Course AID201A, Artificial Intelligence

Abstract—This paper presents a document question answering system that builds a symbolic Knowledge Base (KB) from a structured document and answers questions using search, production rules and inference, without natural language processing (NLP) or retrieval-augmented generation (RAG). Facts are extracted with deterministic pattern rules into triples and frames, questions are grounded against the KB vocabulary, and nine rules produce answers with an explanation trace. On two test documents the system is evaluated for accuracy, coverage and precision.

Keywords—knowledge representation, rule-based reasoning, semantic network, question answering, closed-world assumption

I. Introduction

Question answering over documents is commonly solved with statistical language models. This work instead applies classical AI: knowledge representation, search and inference [1]. The goal is an explainable system in which every answer can be traced to a rule and a source line.

II. Problem and Constraints

The system must (i) accept a document and build a KB, (ii) process questions and reason over the KB, and (iii) generate and evaluate answers. NLP techniques (tokenisation pipelines, stemming, tagging, embeddings) and RAG are excluded. A closed-list of stop words is used only to detect unknown terms so that the system can abstain.

III. System Design

A. Document Processing and KB Construction

Five extraction rules convert text to facts: headings become entities linked by part of; Key: value lines become slots; bullets under a key become multi-valued slots; table rows become frames with units read from headers; and “X is/has …” sentences become is/has facts. Facts are stored as (subject, predicate, value, unit, line) triples. Facts of one subject form a frame [2], and links between entities form a semantic network [3].

B. Question Processing and Reasoning

Grounding is a longest-first dictionary match of the question against entity, attribute and value labels in the KB. Production rules [5] then fire in order: R1 frame comparison; R2 superlative (arg-max/min search); R3 constraint filtering (generate and test); R4 enumeration and counting; R6 yes/no verification under the closed-world assumption [6]; R7 definition; R8 attribute lookup using breadth-first search with property inheritance (depth ≤ 2), plus slot search across frames when no entity is named; R9 fallback ranking or abstention.

C. Answer Generation

Each answer carries the rule fired, a heuristic confidence, the source line and a reasoning trace. If no rule applies and unknown terms remain, the system states that the answer was not found rather than guessing.

D. Justification

A rule-based KB was chosen because it is deterministic, transparent and demonstrates representation, search and reasoning [1], [4]. Its cost is dependence on structured input and on vocabulary present in the document.

IV. Evaluation and Results

Two documents were used: a Solar System fact sheet and an AI course handbook. Each has a question set covering lookup, counting, enumeration, superlatives, filtering, verification, comparison, definition, inference and unanswerable questions. V. Discussion

Errors would arise from questions using words absent from the KB, paraphrases, and prose outside the extraction patterns. These are inherent to a no-NLP design. Unanswerable questions are refused, which keeps precision high.

VI. Conclusion

A symbolic document question answering system was built and evaluated. Future work includes user-defined synonym rules and extraction for more document formats.
